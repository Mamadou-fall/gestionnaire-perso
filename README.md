# Gestionnaire perso

Petite application web personnelle : Épargne, UBA, Cash, Wave, total, dépenses sur Wave, dépensé aujourd'hui, statistiques du mois. Verrouillée par un code à 4 chiffres.
Tout reste dans le téléphone (aucun serveur, aucun compte).

## Mise en ligne (GitHub Pages)
1. Crée un dépôt GitHub (par exemple `gestionnaire-perso`), et envoie-y tous les fichiers de ce dossier.
2. Settings > Pages > Branch : main, dossier / (root) > Save.
3. Ouvre l'adresse affichée, puis « Ajouter à l'écran d'accueil » sur le téléphone.

## Utilisation
- Premier lancement : tu crées ton code à 4 chiffres (deux fois).
- Accueil : touche une carte pour changer le solde (remplacer, ajouter ou retirer).
- Dépenses : chaque dépense se retire de Wave automatiquement ; supprimer une dépense remet le montant sur Wave.
- Statistiques : total du mois, moyenne par jour, jour le plus cher, graphique ; flèches pour changer de mois.
- Réglages : changer le code, sauvegarder / restaurer un fichier, tout effacer.

## À savoir
- Les données sont dans le navigateur de CE téléphone : fais une sauvegarde de temps en temps.
- Le code verrouille l'accès à l'application ; il ne chiffre pas les données stockées.
- Code oublié : le seul recours est de tout effacer (ou de restaurer une sauvegarde).
